# NarrativeGen Public Studio ローカルレビュー手順

対象: `apps/public-studio/`
判定範囲: ローカル候補のみ
所要目安: 10〜15分

## 1. 起動

リポジトリルートの PowerShell で次を実行します。

```powershell
npm run build:public
npm run scan:public
npm run preview:public
```

ブラウザで `http://127.0.0.1:4174/` を開きます。ページ公開や外部サービスへの取り込みは、このレビューには含めません。

## 2. 必須レビュー

| 項目 | 操作 | 合格条件 |
|---|---|---|
| 自動開始 | ページを開く | 「南書庫のレシート」の本文と2つの選択肢が、開始ボタンなしで表示される |
| 選択遷移 | 1つ目の選択肢を選ぶ | ミラの本文へ進み、現在位置が `memory_reframed` になる |
| 再開 | 「最初から」を選ぶ | 最初の本文と2つの選択肢へ戻る |
| ノード本文 | ノード一覧で `desk` を選び、本文末尾へ短い確認文を加える | 上部の物語本文がその場で更新され、保存状態が「自動保存済み」になる |
| 選択肢 | 選択肢1の表示文を変更する | 上部の選択ボタンへ同じ文が反映される |
| 遷移先 | 選択肢1の遷移先を `semantic_end` に変えて、その選択を実行する | `semantic_end` の結末本文が表示される |
| 端末内保存 | ページを再読み込みする | 編集内容が復元され、「このブラウザの下書きを復元しました」と表示される |
| JSON往復 | JSONを書き出し、サンプルへ戻し、書き出したJSONを読み込む | 編集済み本文が戻り、読み込み成功メッセージが出る |
| 初期化 | 「サンプルに戻す」を選ぶ | 正本サンプルから作った公開用コピーへ戻る |
| 簡易検証 | 遷移先と本文を通常範囲で編集する | 「再生を止める問題はありません」が維持される |

## 3. 表示レビュー

- デスクトップ幅で、01 体験 → 02 編集 → 03 仕組み → 商用情報の順序が明瞭か確認します。
- 幅390px前後で、横スクロールが出ず、ノード一覧・編集欄・検証欄が縦に読めるか確認します。
- キーボードの Tab でナビゲーション、物語の選択肢、編集操作へ移動でき、フォーカス位置が見えるか確認します。
- 物語本文と技術識別子が混ざりすぎず、日本語の主要操作が一読で分かるか確認します。

## 4. 境界レビュー

次が見つかった場合は合格にせず、表示場所と文言を返してください。

- アカウント、ログイン、個人情報入力、メール・電話・パスワード欄
- AI設定、API資格情報、provider選択、内部診断、debug操作
- 支払い、checkout、カード情報、subscription、Stripe
- 承認されていない外部リンク、外部スクリプト、外部スタイル
- 商用案内リンク（設定が空の標準ビルドでは非表示が正しい）

商用セクションの説明文があること自体は合格範囲です。このStudio内で契約・購入・送信を完了させないことが境界です。

## 5. 返却形式

```text
Public Studio local review: PASS または FAIL
desktop: PASS/FAIL + 所見
narrow: PASS/FAIL + 所見
story/edit/persistence/json: PASS/FAIL + 所見
boundary: PASS/FAIL + 発見した面
最も大きい編集摩擦: 1件
```

このレビューはローカル候補の人手評価です。物理端末、他ブラウザ、Sites私的保存、公開環境、商用提供の受入れを代替しません。
